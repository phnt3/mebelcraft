# Мебель Крафт: демо-сайт

Демо для предложения клиенту (кухни на заказ, Сыктывкар). Сделан на основе Scroll Kit: HTML, CSS и JS без библиотек и сборки. Чтобы посмотреть, откройте `index.html`.

## Структура сайта

1. **Hero.** Фото кухни на весь экран, заголовок «Кухни на заказ», кнопки «Бесплатный замер» и «Расчёт дистанционно».
2. **3D-сборка кухни.** Объёмная модель на CSS 3D. Пока посетитель листает, кухня собирается: корпуса, столешница и фартук с подсветкой, фасады. В конце ящики выдвигаются, а верхние дверцы поднимаются, как на фурнитуре Blum. Модель реагирует на мышь.
3. **Почему мы.** Текст загорается по словам: «без посредников, по договору».
4. **Бегущая строка.** Замер, договор, гарантия, рассрочка, график.
5. **Работы.** Горизонтальная лента с фото: угловая, прямая, с островом.
6. **Условия.** Главы: замер, договор и гарантия, рассрочка, онлайн-расчёт.
7. **«Плёнка → Эмаль».** Экран раскрывается кругом: эмаль по цене ПВХ.
8. **Материалы.** 3D-образцы фасадов (эмаль, графит, дуб, рифлёный, мрамор) летят с параллаксом.
9. **Акции стопкой.** −50% на Blum, гарантия 24 мес / 10 лет, рассрочка.
10. **Контакты.** Телефон, часы, адрес, ссылка на Яндекс.Карты, форма заявки.

Палитра взята с фото работ: графит `#1b1a18`, тёплый белый (эмаль) `#efebe4`, дуб `#c49b6a`. Цвета меняются в `:root` файла `kraft.css`.

## Что заменить перед показом и запуском

- **Телефон.** `+7 (900) 000-00-00` — заглушка. Встречается 4 раза в `index.html` (шапка, контакты, кнопка звонка внизу на телефоне). Ищите `79000000000` и `000-00-00`.
- **Фото.** 4 фото взяты из объявления на Авито (вотермарка обрезана) и лежат в `assets/k1–k4.jpg`. Для демо этого хватит, но для настоящего сайта нужно разрешение клиента или его исходники в хорошем качестве.
- **Форма.** Работает в демо-режиме: проверяет телефон и показывает «Заявка принята», но никуда не отправляет. Для запуска подключите Telegram-бота, почту или CRM в `kraft.js` (место отмечено `TODO`).
- **Тексты.** Взяты из объявления. Цифр, отзывов и «лет на рынке» нет, чтобы не придумывать. Если клиент даст реальные данные, их можно добавить.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка и все тексты |
| `kit.css`, `kit.js` | движок Scroll Kit |
| `kraft.css` | тема Мебель Крафт: палитра, материалы, 3D, адаптив |
| `kraft.js` | 3D-модель кухни, сцена сборки, маска телефона в форме |
| `assets/` | фото работ, около 280 КБ |

Сайт не проверялся в настоящем браузере, только синтаксис. Перед отправкой клиенту пролистайте его на компьютере и на телефоне.
